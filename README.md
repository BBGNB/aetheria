# Aetheria

A mobile-first turn-based JRPG, rendered to canvas with vanilla JS. No build
step, no assets — everything is drawn procedurally.

## Play

Visit the live build: https://bbgnb.github.io/aetheria/

On mobile, tap your browser's menu → **Add to Home Screen** to install it as
an app (full-screen, offline-capable after first load).

## Run locally

```
node server.js
```

Then open `http://localhost:8080`.
